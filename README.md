# 🌍 AQI Detection System

A web-based Air Quality Index (AQI) detection system that provides real-time air quality insights based on user location.

## 🚀 Features
- 🌐 Real-time AQI data using external APIs  
- 📊 Displays pollutant levels (PM2.5, PM10, CO, NO2, O3)  
- 🎨 Color-based AQI categorization  
- 💻 Clean and responsive UI  

## 🛠️ Tech Stack
- HTML  
- CSS  
- JavaScript  
- API Integration
